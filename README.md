# Ophion · The Blind Seer

**Useful discoveries. Preserved in one place.**

A curated vault of tools, technical tricks, and learning resources. Organised into folders, searchable by tags, and reviewed before publication.

[Enter the vault →](https://ophion-tool-vault.grimmoir.workers.dev/) · [About Ophion](https://ophion-tool-vault.grimmoir.workers.dev/about)

> This repository documents Ophion. It does not contain the application source code.

## Find. Save. Share.

- **Find what you need.** Browse folders or search names, descriptions, categories, and tags.
- **Look before you use.** Tool listings include trust, risk, and pricing labels.
- **Keep what matters.** Sign in to bookmark entries across the vault.
- **Add a discovery.** Submit a tool, trick, or resource for review, then manage your contributions.
